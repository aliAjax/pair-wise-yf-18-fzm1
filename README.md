# hxyfront-62006 珠宝镶嵌 · 批次工作台

面向珠宝镶嵌工作室的宝石分拣批次系统，解决纸卡分拣时同一镶嵌位被两批同时占用的问题。

## 功能

- **批次工作台**：按订单新建批次，录入宝石的编号、形状、尺寸、克拉、净度、镶嵌位与状态；支持编辑、删除。
- **选中批次后按形状筛选**：形状筛选只作用于当前选中批次的宝石明细。
- **镶嵌位唯一占用**：未完成批次中，同一镶嵌位全工作室只能被一颗宝石占用——
  跨批次冲突、同批次重复都会被拦截，并提示当前占用方。
- **完成即释放**：批次标记完成后其镶嵌位立即释放，可用于下一单。
- **缺陷备注随宝石保留**：缺陷备注是宝石自身属性，可随时补充，批次完成、状态流转都不会清空。
- **订单清单**：按订单查看，只列出该订单「已分拣」的宝石，并显示随石保留的缺陷备注；
  待分拣 / 缺陷待确认的宝石不计入清单。
- **持久化**：数据保存在浏览器 localStorage，关闭页面重开可接着处理。

## 代码结构（数据 / 规则 / 页面分离）

```
src/
├── domain/types.ts        # 领域模型与类型（Batch / Gem / 状态枚举）
├── data/                  # 数据层：只负责存取与选项常量
│   ├── constants.ts       #   形状 / 净度 / 状态选项、存储键
│   ├── seed.ts            #   首次打开的演示数据
│   └── storage.ts         #   localStorage 读写（不包含业务规则）
├── rules/studioRules.ts   # 规则层：纯函数，镶嵌位占用、校验、清单口径
├── hooks/useStudio.ts     # 应用动作：把页面操作接到数据层与规则层
├── components/            # 页面层：BatchSidebar / GemForm / GemTable /
│                          #         SlotBoard / OrderPanel
└── App.tsx                # 组装页面
```

- 改下拉选项、存储位置 → `data/`
- 改镶嵌位判定、订单清单口径、必填校验 → `rules/studioRules.ts`
- 改界面 → `components/`
