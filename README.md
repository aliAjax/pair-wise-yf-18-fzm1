# 珠宝镶嵌 · 批次工作台

面向珠宝镶嵌工作室的宝石分拣工作台：按批次录入宝石、管理镶嵌位占用、保留缺陷备注，并按订单输出已分拣清单。数据保存在浏览器本地，关闭页面后重开可继续处理。

## 功能

- **批次工作台**：新建/选择分拣批次（批次编号 + 订单号），录入宝石的编号、形状、尺寸、克拉、净度、镶嵌位、状态，以及缺陷备注。
- **选中批次后按形状筛选**：筛选条只列出该批次实际出现过的形状，带每类数量。
- **镶嵌位占用规则**：同一订单的**未完成批次**中，同一镶嵌位只能被一颗宝石占用，重复占用会在保存时被拦截并指明占用方；已完成批次释放镶嵌位，位置可复用；不同订单互不影响。
- **缺陷备注随宝石保留**：备注是宝石自身字段，编辑其他字段或批次完工都不会清空；「缺陷待处理 / 待复检」状态必须填写备注。
- **订单清单**：只显示该订单状态为「已分拣」的宝石及合计克拉，待分拣/异常处理中的宝石不进入清单。
- **批次完工 / 重新打开**：批次内仍有未处理完的宝石时不允许完工；重新打开会先检查镶嵌位是否与现存未完成批次冲突。
- **本地持久化**：所有改动即时写入 `localStorage`（键 `jewelry-bench/v1`），重开页面接着处理；环境不支持时退回内存存储。

## 分层结构（数据 / 规则 / 页面分开维护）

```
src/
├── data/                 # 数据层
│   ├── dictionaries.ts   #   形状、净度、状态、镶嵌位候选项等字典
│   ├── seed.ts           #   首次使用的演示数据与存储键
│   └── storage.ts        #   localStorage 读写与存档校验
├── rules/                # 规则层（纯函数，不依赖 React/DOM）
│   ├── validators.ts     #   镶嵌位互斥、字段校验、完工/重开约束
│   └── selectors.ts      #   形状筛选、订单清单、统计等查询
├── state/
│   └── useBench.ts       # 状态层：数据状态 + 持久化 + 调用规则的动作
├── components/           # 页面层
│   ├── GemForm.tsx       #   宝石录入/编辑表单
│   ├── GemTable.tsx      #   宝石清单与形状筛选条
│   ├── OrdersView.tsx    #   订单清单（仅已分拣）
│   ├── BatchModal.tsx    #   新建批次弹窗
│   └── Modal.tsx         #   通用弹窗
├── types.ts              # 领域模型类型
└── App.tsx               # 页面组装
```

调整选项改 `data/dictionaries.ts`；调整业务约束改 `rules/`；调整界面改 `components/` 与 `styles.css`，三者互不耦合。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62006
```

其他命令：

```bash
npm run typecheck  # 严格类型检查
npm test           # 规则层 16 条冒烟测试（纯 node 执行）
npm run build      # 类型检查 + 生产构建
```

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖）
